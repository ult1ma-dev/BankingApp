# SkyPro Project Homework

## Цель проекта

Цель проекта — разработать на Python набор инструментов для обработки данных
банковских операций. Реализованные функции позволяют безопасно отображать
номера карт и счетов, преобразовывать даты, фильтровать операции по статусу и
валюте, а также сортировать их по дате.

Проект является учебным и находится в разработке: новый функционал добавляется
по мере прохождения курса.

## Возможности

- маскировка номера банковской карты;
- маскировка номера банковского счета;
- обработка строки, содержащей название карты или счета вместе с номером;
- проверка корректности введенных банковских реквизитов;
- преобразование даты из ISO-формата в формат `ДД.ММ.ГГГГ`;
- фильтрация операций по статусу;
- последовательная выдача транзакций в указанной валюте;
- последовательная выдача описаний транзакций;
- генерация номеров банковских карт в заданном диапазоне;
- сортировка операций по дате в выбранном порядке;
- логирование выполнения функций в консоль или файл;
- загрузка финансовых транзакций из JSON-файла;
- конвертация сумм транзакций из USD и EUR в рубли.

## Функции проекта

| Функция | Назначение | Пример результата |
|---|---|---|
| `get_mask_card_number()` | Маскирует 16-значный номер карты | `7000 79** **** 6361` |
| `get_mask_account()` | Оставляет последние четыре цифры счета | `**4305` |
| `mask_account_card()` | Определяет тип реквизитов и выбирает подходящую маску | `Visa Platinum 7000 79** **** 6361` |
| `get_date()` | Преобразует дату из ISO-формата | `11.03.2024` |
| `filter_by_state()` | Возвращает операции с указанным статусом | Только операции со статусом `EXECUTED` |
| `sort_by_date()` | Возвращает операции, отсортированные по дате | По убыванию или возрастанию |
| `filter_by_currency()` | Создаёт итератор транзакций в указанной валюте | Только транзакции в `USD` |
| `transaction_descriptions()` | Создаёт итератор описаний транзакций | `Перевод организации` |
| `card_number_generator()` | Генерирует номера карт в заданном диапазоне | `0000 0000 0000 0001` |
| `log()` | Логирует вызов, результат и ошибки функции | Вывод в консоль или файл |
| `read_json_file()` | Загружает список транзакций из JSON-файла | Список словарей или `[]` |
| `convert_to_rub()` | Возвращает сумму транзакции в рублях | Значение типа `float` |

### Обработка названия и номера

Функция `mask_account_card()` принимает одну строку. Номер должен находиться
после названия и отделяться от него пробелом.

```python
from src.widget import mask_account_card

card = mask_account_card("Visa Platinum 7000792289606361")
account = mask_account_card("Счет 73654108430135874305")

print(card)
print(account)
```

Результат:

```text
Visa Platinum 7000 79** **** 6361
Счет **4305
```

Функция проверяет входные данные:

- строка не должна быть пустой;
- строка должна содержать название и номер;
- номер должен состоять только из цифр;
- номер карты должен содержать 16 цифр;
- номер счета должен содержать 20 цифр.

При нарушении этих правил функция вызывает `ValueError` с описанием проблемы.

### Преобразование даты

```python
from src.widget import get_date

formatted_date = get_date("2024-03-11T02:26:18.671407")
print(formatted_date)
```

Результат:

```text
11.03.2024
```

Дата разбирается функцией `datetime.fromisoformat()`. Если переданная строка
не соответствует поддерживаемому ISO-формату, Python вызовет `ValueError`.

### Фильтрация операций по статусу

Функция `filter_by_state()` принимает список словарей и возвращает новый
список только с операциями, у которых значение `state` совпадает с выбранным
статусом. По умолчанию используется статус `EXECUTED`.

```python
from src.processing import filter_by_state

operations = [
    {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
    {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
    {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},
    {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"},
]

executed_operations = filter_by_state(operations)
canceled_operations = filter_by_state(operations, "CANCELED")

print([operation["id"] for operation in executed_operations])
print([operation["id"] for operation in canceled_operations])
```

Результат:

```text
[41428829, 939719570]
[594226727, 615064591]
```

Исходный список не изменяется.

### Сортировка операций по дате

Функция `sort_by_date()` возвращает новый список операций, отсортированный по
значению ключа `date`. По умолчанию используется сортировка по убыванию: от
самой новой операции к самой старой.

```python
from src.processing import sort_by_date

newest_first = sort_by_date(operations)
oldest_first = sort_by_date(operations, reverse=False)

print([operation["id"] for operation in newest_first])
print([operation["id"] for operation in oldest_first])
```

Результат:

```text
[41428829, 615064591, 594226727, 939719570]
[939719570, 594226727, 615064591, 41428829]
```

Параметр `reverse` задает порядок сортировки:

- `True` — по убыванию;
- `False` — по возрастанию.

Строки дат записаны в ISO-формате, поэтому их можно сортировать в виде строк.
Исходный список при сортировке также не изменяется.

#### Фильтрация транзакций по валюте

Функция `filter_by_currency()` принимает список транзакций и код валюты. Она
возвращает итератор и поочередно выдаёт подходящие транзакции в исходном
порядке, не создавая заранее новый список.

```python
from src.generators import filter_by_currency

usd_transactions = filter_by_currency(transactions, "USD")

for transaction in usd_transactions:
    print(transaction["id"])
```

Результат:

```text
939719570
142264268
895315941
```

После выдачи всех подходящих транзакций следующий вызов `next()` завершает
итератор исключением `StopIteration`. Сравнение кода валюты учитывает регистр:
`USD` и `usd` считаются разными значениями.

#### Последовательная выдача описаний транзакций

Функция `transaction_descriptions()` возвращает итератор, который выдаёт
значение `description` каждой транзакции по очереди.

```python
from src.generators import transaction_descriptions

descriptions = transaction_descriptions(transactions)

for _ in range(5):
    print(next(descriptions))
```

Результат:

```text
Перевод организации
Перевод со счета на счет
Перевод со счета на счет
Перевод с карты на карту
Перевод организации
```

Исходный порядок сохраняется. После последнего описания следующий вызов
`next()` завершает итератор исключением `StopIteration`.

#### Генерация номеров банковских карт

Функция `card_number_generator()` принимает аргументы `start` и `stop` —
начало и конец диапазона — и возвращает итератор номеров карт. Значение
`stop` входит в диапазон.

```python
from src.generators import card_number_generator

for card_number in card_number_generator(1, 5):
    print(card_number)
```

Результат:

```text
0000 0000 0000 0001
0000 0000 0000 0002
0000 0000 0000 0003
0000 0000 0000 0004
0000 0000 0000 0005
```

Каждое число дополняется нулями слева до 16 цифр и разделяется пробелами на
четыре группы. Допустимый диапазон из задания — от `1` до
`9999999999999999`.

### Логирование выполнения функций

Декоратор `log()` регистрирует время начала и окончания работы функции,
продолжительность выполнения и результат. При возникновении исключения в лог
записываются текст ошибки, позиционные и именованные аргументы, после чего
исходное исключение выбрасывается повторно.

Без имени файла сообщения выводятся в консоль:

```python
from src.decorators import log


@log()
def add_numbers(a: int, b: int) -> int:
    return a + b


add_numbers(1, 2)
```

Чтобы дописывать сообщения в файл, передайте путь через `filename`:

```python
@log(filename="mylog.txt")
def add_numbers(a: int, b: int) -> int:
    return a + b
```

### Загрузка транзакций и конвертация валют

Функция `read_json_file()` читает список транзакций из JSON-файла. Для
отсутствующего, пустого или неподходящего файла она возвращает пустой список.

```python
from src.external_api import convert_to_rub
from src.utils import read_json_file

transactions = read_json_file("data/operations.json")
amount_in_rubles = convert_to_rub(transactions[0])
```

Для конвертации USD и EUR требуется ключ Exchange Rates Data API. Создайте
локальный файл `.env` на основе `.env.example` и задайте переменную:

```text
EXCHANGE_RATES_API_KEY=your_real_api_key
```

Файл `.env` исключён из Git, а `.env.example` содержит только безопасный
шаблон без настоящего ключа.
