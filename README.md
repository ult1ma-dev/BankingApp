# SkyPro Project Homework

Учебный Python-проект с функциями для маскировки банковских реквизитов и
преобразования дат. Проект позволяет безопасно отображать номера банковских
карт и счетов, сохраняя только необходимые части исходных данных.

## Возможности

- маскировка номера банковской карты;
- маскировка номера банковского счета;
- обработка строки, содержащей название карты или счета вместе с номером;
- проверка корректности введенных банковских реквизитов;
- преобразование даты из ISO-формата в формат `ДД.ММ.ГГГГ`.

## Функции проекта

| Функция | Назначение | Пример результата |
|---|---|---|
| `get_mask_card_number()` | Маскирует 16-значный номер карты | `7000 79** **** 6361` |
| `get_mask_account()` | Оставляет последние четыре цифры счета | `**4305` |
| `mask_account_card()` | Определяет тип реквизитов и выбирает подходящую маску | `Visa Platinum 7000 79** **** 6361` |
| `get_date()` | Преобразует дату из ISO-формата | `11.03.2024` |

## Использование

Функции можно импортировать в другой модуль или вызвать в интерактивной
консоли Python.

### Маскировка номера карты

```python
from src.masks import get_mask_card_number

masked_card = get_mask_card_number("7000792289606361")
print(masked_card)
```

Результат:

```text
7000 79** **** 6361
```

### Маскировка номера счета

```python
from src.masks import get_mask_account

masked_account = get_mask_account("73654108430135874305")
print(masked_account)
```

Результат:

```text
**4305
```

### Обработка названия и номера

Функция `mask_account_card()` принимает одну строку. Номер должен находиться
после названия и отделяться от него пробелом.

```python
from src.widget import mask_account_card

card = mask_account_card("Visa Platinum 7000792289606361")
account = mask_account_card("Счет 73654108430135874305")

print(card)
print(account)
```

Результат:

```text
Visa Platinum 7000 79** **** 6361
Счет **4305
```

Функция проверяет входные данные:

- строка не должна быть пустой;
- строка должна содержать название и номер;
- номер должен состоять только из цифр;
- номер карты должен содержать 16 цифр;
- номер счета должен содержать 20 цифр.

При нарушении этих правил функция вызывает `ValueError` с описанием проблемы.

### Преобразование даты

```python
from src.widget import get_date

formatted_date = get_date("2024-03-11T02:26:18.671407")
print(formatted_date)
```

Результат:

```text
11.03.2024
```

Дата разбирается функцией `datetime.fromisoformat()`. Если переданная строка
не соответствует поддерживаемому ISO-формату, Python вызовет `ValueError`.
