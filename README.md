# SkyPro Project Homework

## Цель проекта

Цель проекта — разработать на Python набор инструментов для обработки данных
банковских операций. Реализованные функции позволяют безопасно отображать
номера карт и счетов, преобразовывать даты, фильтровать операции по статусу и
сортировать их по дате.

Проект является учебным и находится в разработке: новый функционал добавляется
по мере прохождения курса.

## Возможности

- маскировка номера банковской карты;
- маскировка номера банковского счета;
- обработка строки, содержащей название карты или счета вместе с номером;
- проверка корректности введенных банковских реквизитов;
- преобразование даты из ISO-формата в формат `ДД.ММ.ГГГГ`;
- фильтрация операций по статусу;
- сортировка операций по дате в выбранном порядке.

## Функции проекта

| Функция | Назначение | Пример результата |
|---|---|---|
| `get_mask_card_number()` | Маскирует 16-значный номер карты | `7000 79** **** 6361` |
| `get_mask_account()` | Оставляет последние четыре цифры счета | `**4305` |
| `mask_account_card()` | Определяет тип реквизитов и выбирает подходящую маску | `Visa Platinum 7000 79** **** 6361` |
| `get_date()` | Преобразует дату из ISO-формата | `11.03.2024` |
| `filter_by_state()` | Возвращает операции с указанным статусом | Только операции со статусом `EXECUTED` |
| `sort_by_date()` | Возвращает операции, отсортированные по дате | По убыванию или возрастанию |

Результат:


### Обработка названия и номера

Функция `mask_account_card()` принимает одну строку. Номер должен находиться
после названия и отделяться от него пробелом.

```python
from src.widget import mask_account_card

card = mask_account_card("Visa Platinum 7000792289606361")
account = mask_account_card("Счет 73654108430135874305")

print(card)
print(account)
```

Результат:

```text
Visa Platinum 7000 79** **** 6361
Счет **4305
```

Функция проверяет входные данные:

- строка не должна быть пустой;
- строка должна содержать название и номер;
- номер должен состоять только из цифр;
- номер карты должен содержать 16 цифр;
- номер счета должен содержать 20 цифр.

При нарушении этих правил функция вызывает `ValueError` с описанием проблемы.

### Преобразование даты

```python
from src.widget import get_date

formatted_date = get_date("2024-03-11T02:26:18.671407")
print(formatted_date)
```

Результат:

```text
11.03.2024
```

Дата разбирается функцией `datetime.fromisoformat()`. Если переданная строка
не соответствует поддерживаемому ISO-формату, Python вызовет `ValueError`.

### Фильтрация операций по статусу

Функция `filter_by_state()` принимает список словарей и возвращает новый
список только с операциями, у которых значение `state` совпадает с выбранным
статусом. По умолчанию используется статус `EXECUTED`.

```python
from src.processing import filter_by_state

operations = [
    {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
    {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
    {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},
    {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"},
]

executed_operations = filter_by_state(operations)
canceled_operations = filter_by_state(operations, "CANCELED")

print([operation["id"] for operation in executed_operations])
print([operation["id"] for operation in canceled_operations])
```

Результат:

```text
[41428829, 939719570]
[594226727, 615064591]
```

Исходный список не изменяется.

### Сортировка операций по дате

Функция `sort_by_date()` возвращает новый список операций, отсортированный по
значению ключа `date`. По умолчанию используется сортировка по убыванию: от
самой новой операции к самой старой.

```python
from src.processing import sort_by_date

newest_first = sort_by_date(operations)
oldest_first = sort_by_date(operations, reverse=False)

print([operation["id"] for operation in newest_first])
print([operation["id"] for operation in oldest_first])
```

Результат:

```text
[41428829, 615064591, 594226727, 939719570]
[939719570, 594226727, 615064591, 41428829]
```

Параметр `reverse` задает порядок сортировки:

- `True` — по убыванию;
- `False` — по возрастанию.

Строки дат записаны в ISO-формате, поэтому их можно сортировать в виде строк.
Исходный список при сортировке также не изменяется.
